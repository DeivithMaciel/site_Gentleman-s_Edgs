# 💈 Gentleman's Edge

A modern and responsive landing page for a premium barbershop.

This project was built to practice modern Front-End development using React and TypeScript, focusing on clean UI, reusable components, and responsive design.

## 🚀 Live Demo

You can access the live project here:
👉 https://site-gentleman-s-edgs.vercel.app

---

## ✨ Features

* Modern barbershop landing page design
* Fully responsive layout (desktop, tablet, mobile)
* Image carousel for haircuts
* Customer testimonials section
* Contact form
* Navigation menu with smooth scrolling
* Loading animation for better UX
* Styled-components for scoped styling
* Fake API for products, haircuts, and testimonials

---

## 🛠️ Technologies Used

* React
* TypeScript
* Styled-components
* Vite
* Fake API (local services)
* Responsive design
